# Lab14 — Структуровані типи даних

## Опис
Ця програма реалізує роботу з масивом структур типу "Студент".

Кожен студент має наступні поля:
- ім’я
- вік
- середній бал

Програма:
- зчитує дані з файлу
- виводить їх у консоль
- сортує студентів за середнім балом
- записує результат у файл

---

## Структура проєкту

lab14/
├── assets/        (вхідні дані)
├── src/           (вихідний код)
├── doc/           (звіт)
├── test/          (тести)
├── Makefile
└── README.md

---

## Компіляція

gcc src/main.c src/lib.c -o dist/main.bin

---

## Запуск

./dist/main.bin assets/input.txt dist/output.txt
